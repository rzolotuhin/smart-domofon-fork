# Smart intercom based on ESP8266
**English** | [Русский](https://github.com/rzolotuhin/smart-domofon-fork/blob/master/README.md)

This device can accept or reject incoming call to intercom. It only works with coordinate line intercoms. Tested with Visit, Cyfral, Metakom, Altis russian intercoms.

#### There are 3 versions of this project:
1. [Ready to use board](https://github.com/rzolotuhin/smart-domofon-fork/blob/master/ge1mer/README_EN.md) 👍
2. [DIY](https://github.com/rzolotuhin/smart-domofon-fork/blob/master/esphome/README_EN.md) 👌
3. [Old version with native firmware](https://github.com/rzolotuhin/smart-domofon-fork/blob/master/native/README_EN.md) 💩
