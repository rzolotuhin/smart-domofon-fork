# Умный домофон на ESP8266
[English](https://github.com/rzolotuhin/smart-domofon-fork/blob/master/README_EN.md) | **Русский**

Устройство умеет открывать домофон при входящем вызове. Работает только с координатными домофонами. Проверено с домофонами Visit, Cyfral, Metakom, Altis.

#### Сейчас есть 3 версии проекта:
1. [В виде готовой платы](https://github.com/rzolotuhin/smart-domofon-fork/blob/master/ge1mer/README.md) 👍
2. [В виде набора для сборки](https://github.com/rzolotuhin/smart-domofon-fork/blob/master/esphome/README.md) 👌
3. [Старая версия с нативной прошивкой](https://github.com/rzolotuhin/smart-domofon-fork/blob/master/native/README.md) 💩
